# 灵场 Lab · 显化能量测试 MVP

这是一个可以直接打开、演示和部署的静态产品原型：

- 中文用户体验，定位为“显化自我探索 + 东方时间意象 + 专属视觉壁纸”。
- 30 道自我探索问题，完成后生成能量指数、关键词和一份小仪式建议。
- 出生日期、出生时间、出生地点为可选输入，第一版不宣称进行严肃八字诊断。
- 根据结果从“素材库”中抽取一套匹配的视觉资产配方：当前演示包含 12 种不同构图的月光、花野、星象门户、水镜、极光、星尘和植物轨道场景，并用回答、显化目标与出生信息作为可复现的选择种子。
- 结果页直接渲染被抽取的素材库场景，不再只是固定模板换颜色；同时可下载 PNG 手机壁纸，并通过低算力的光晕、星尘、轨道和花瓣运动生成 6 秒轻动态 WebM。
- 壁纸采用“空灵星象花园”视觉：低对比细线、雾化光晕、星空与植物意象，壁纸内部不嵌入显化文案。
- “购买完整版本”目前只是演示按钮，不接入支付；后续可以替换为电商平台商品链接。
- 页面中保留了对体验边界的说明：它用于自我探索与视觉仪式，不构成科学、医学、心理诊断、投资判断或结果保证。

## 本地预览

直接双击 `index.html` 即可打开。也可以把整个文件夹部署到任意静态托管服务。

## 下一阶段建议

1. 将当前前端素材库扩展为对象存储/CDN 中的真实图片库：每张图片带有元素、色系、构图、显化主题、季节和版权字段，服务端按标签过滤后再按种子抽取。
2. 将 `beginGeneration()` 替换为服务端调用：先生成能量摘要，再调用图像模型生成高清壁纸或从百万级素材库中返回一张有版权记录的图片。
3. 在服务端加入出生信息的历法/八字计算，并在产品文案里说明采用的算法和边界；当前版本只做视觉意象映射，不宣称是严谨喜用神计算。
3. 保持网站不接支付，把“buy-button”指向电商平台的一个套餐商品链接，静态 PNG 和动态 WebM 一起交付。
4. 通过简单的表单或匿名订单号，把“完整报告”作为 PDF 或长图交付。
5. 部署到 GitHub Pages、Vercel 或 Cloudflare Pages，生成稳定的商品详情页链接；当前 raw.githack 地址适合演示，正式售卖建议使用自己的 Pages/域名。
